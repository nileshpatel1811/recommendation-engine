# Gold Loan Recommendation Engine (Working Name)

## Vision

Help borrowers choose the best lender for their situation instead of comparing only interest rates.

We are not a lender.
We are an independent recommendation platform.

---

# Problem

Borrowers waste time visiting multiple banks and NBFCs because every lender has different:

- Interest rates
- Loan amount eligibility
- Documentation requirements
- Approval criteria
- Processing time

Most people only discover this after visiting multiple branches.

---

# Solution

Ask a few smart questions.

Recommend the top lenders.

Explain why.

Explain tradeoffs.

Help borrowers make better financial decisions.

---

# MVP Goal

Validate whether borrowers trust personalized lender recommendations.

Success is NOT measured by revenue.

Success is measured by whether users say the recommendation influenced their decision.

# Core Questions

1. What are you trying to do?
    - New Loan
    - Switch Existing Loan
    - Compare Options

2. What matters most?
    - Lowest Cost
    - Fastest Process
    - Highest Loan Amount
    - Highest Approval Chance
    - Best Overall

3. How much money do you need?

4. Which city are you in?

5. Dynamic Question
    - Existing Bank Account
    OR
    - Current Lender

---

# Recommendation Principles

Never recommend based on interest rate alone.

Recommendation should consider:

- Cost
- Speed
- Convenience
- Existing relationship
- Approval likelihood
- Loan amount
- Other lender-specific rules
